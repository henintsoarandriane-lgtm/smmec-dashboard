# SMMEC - Dashboard Interactif

Projet de stage Licence 2 DA2I - EMIT Université de Fianarantsoa

## Description

Dashboard interactif pour la gestion des demandes de crédit et d'épargne à la SMMEC Ambositra.

## Technologies

- Frontend : HTML5, CSS3, JavaScript
- Backend : Node.js, Express
- Base de données : MySQL
- Authentification : JWT + bcrypt
- Temps réel : Socket.IO
- Cartographie : Leaflet
- Graphiques : Chart.js

## Installation

```bash
cd backend
npm install
npm run dev
